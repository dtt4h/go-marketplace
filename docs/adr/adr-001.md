## ADR-001: Архитектура проекта
Дата: 19.07.2026  
Статус: ожидание

## Контекст 
Нужно разработать MVP маркетплейса. Ожидается небольшая команда и ограниченный бюджет. Система должна позволять быстро выпускать новые функции.

## Решение
Использовать модульный монолит.

Структура: Frontend -> Backend -> PostgreSQL

Backend-модули разделяем на бизнес-модули:
- Auth;
- Users;
- Products;
- Orders;
- Payments.

## Рассмотренные альтернативы
### Микросервисы 
Плюсы: 
- Независимый деплой;
- Масштабирование сервисов.
Минусы:
- Сложность инфраструктуры;
- Больше времени разработки.

## Заключение
Плюсы:
- Быстрее разработка;
- Проще поддержка;
- Легко выделить в сервисы позже.

Минусы:
- Сильная связность внутри приложения.
